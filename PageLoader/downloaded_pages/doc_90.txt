Ссылку можно вносить по истечении 7 дней с начала обсуждения при отсутствии аргументированных возражений или при наличии консенсуса за добавление. Исключение — не требуется открытие темы для добавления ссылки через отдельное свойство, если она уже имеется в шаблоне с использованием свойства учётная запись в социальных медиа (P553) или описывается в источниках (P1343), а также для иных изменений ссылок, уже имеющихся в шаблоне[1]. Этот шаблон реализован на основе Lua:с использованием модуля External links;с использованием модуля External links/data. Данный шаблон автоматически подставляет ссылки на социальные сети, службы фото- и видеохостинга, библиографические каталоги и т. д., которые определены для текущего элемента на Викиданных. Для редактирования внешних ссылок в конкретной статье, находясь в ней, перейдите по ссылке «Элемент Викиданных» в левом меню (блок «В других проектах»). Единственный параметр позволяет модифицировать цвет групповых заголовков для получившейся навигационной таблицы, возможные цвета смотрите в шаблоне {{Цвет}}. {{Внешние ссылки}} {{Внешние ссылки|Животные}} Для добавления, редактирования и удаления ссылок в шаблоне без перехода на сайт Викиданных существует специальный гаджет. Если в шаблоне заполнен только раздел «В библиографических каталогах», его стоит размещать после всех навигационных таблиц. Если же есть другие разделы, в особенности — «Социальные сети» и/или «Аудио-, видео- и фотохостинги», то шаблон желательно размещать до остальных навигационных шаблонов, чтобы он визуально шёл сразу после раздела «Ссылки», если такой есть. Шаблон не виден в мобильной версии, то есть более чем половине читателей Википедии. Не является основанием снятия ш:нет ссылок, который просит добавить текстом источники в тело статьи. Редактирование Все значения берутся из Викиданных, для их изменения необходимо изменить информацию на Викиданных напрямую, либо воспользоваться существующим гаджетом. Если гаджет по каким-либо причинам не работает, можете отредактировать ссылку напрямую на Викиданных: Слева, в меню «В других проектах» найдите ссылку «Викиданные» и перейдите по ней (если ссылки нет, то потребуется создать новый элемент и связать его с существующей статьёй). На появившейся странице найдите раздел «Утверждения». В таблице ниже найдите сайт, ссылку на который Вы хотите добавить. Если в таблице строка «Викиданные» имеет вид «P553 / P554 / Q219523», то делаете следующее: Создаёте новое утверждение (кнопка «[ добавить ]»). Название нового свойства: «учётная запись в социальных медиа». Значение нового свойства: тип социальной сети, профиль в которой Вы хотите добавить в список ссылок. Например, «Твиттер». Нажимаете «Сохранить», и, после сохранения, на кнопку «Редактировать» (она появится справа от названия соц. сети). Нажимаете «Квалификатор» — это добавит поля для добавления квалификаторов. В поле «Свойство» указываете «адрес в социальных медиа». В появившемся после этого поле указываете адрес в Твиттер, например, «myaccount». Нажимаете «Сохранить». Поздравляем, Вы добавили ссылку на аккаунт Твиттера. Если в таблице строка «Викиданные» имеет вид «P549», то делаете следующее: Создаёте новое утверждение (кнопка «[ добавить ]»). Название нового свойства: «P549» (появится название сайта). В качестве значения свойства — цифровой или цифробуквенный ID аккаунта на сайте. Например, если для сайта «Родовод» ссылка выглядит как http://ru.rodovid.org/wk/Person:57500 , причём последние цифры меняются от человека к человеку, значит именно «57500» и является ID аккаунта и именно его нужно указывать в качестве значения свойства. Нажимаете «Сохранить». Поздравляем, Вы добавили ссылку на сайт. С помощью гаджета эти действия делаются намного проще. Символ галочки или крестика в последнем столбце обозначает, соответствует ли локальная ссылка для свойства хотя бы одной из ссылок, перечисленных в Викиданных. Если нет, то заодно выводятся ссылка из Викиданных. К сожалению, есть лимит на 400 элементов на страницу, поэтому проверка работает только для половины таблицы. При необходимости можно в Модуль:External links/Documentation#L-6 изменить сдвиг и установить проверку для другой половины.
